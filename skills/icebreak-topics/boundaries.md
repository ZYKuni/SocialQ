# 共同讨厌的边界（规则 H5、S6）

共同讨厌能拉近距离，但很容易变成冒犯。原则只有一条：**吐槽事，不吐槽人**。整段对话最多用一次，不能作为第一句。

## 可以吐槽

| 类型 | 例子 |
| --- | --- |
| 日常小麻烦 | 早八、排长队、下雨天出门、手机没电 |
| 观看体验 | 被剧透、广告太长、烂尾的结局、注水的剧集 |
| 游戏体验 | 掉线、匹配到挂机的队友、抽卡保底歪了 |
| 学习和工作 | 赶 DDL、无效的会、写不完的报告 |
| 套路和梗 | 烂俗剧情套路、过度营销 |

## 不能碰

| 类型 | 原因 |
| --- | --- |
| 具体的真人（包括明星、主播、同学） | 对方可能喜欢，也可能被截图传播 |
| 地域、性别、职业、年龄等群体 | 属于刻板印象，容易冒犯 |
| 政治、宗教、民族 | 敏感话题，违反 H3 |
| 外貌、身材、健康 | 敏感且伤人 |
| 前任和感情经历 | 太私人，不适合初次聊天 |
| 对方社交状态里写着喜欢的东西 | 等于当面否定对方 |

## 判断方法

分身准备用一条共同讨厌时，按顺序检查：

1. 吐槽的对象是一件事，还是一个人或一群人？是人就不用。
2. 它在不在对方的兴趣或“喜欢”里？在就不用。
3. 换成对方的朋友看到这句话，会不会觉得被冒犯？会就不用。
