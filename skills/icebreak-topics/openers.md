# 开场白样例

`{对象}` `{类型}` `{活动}` 等是占位符，由分身按双方的社交状态填写。每类先给“自然”的写法，再给“生硬”的反例和原因。分身生成开场白时，按主人自己的说话风格改写，不要照抄。

## A 类：同一对象

自然：
1. 看到你也在听{歌手}，最近那首{歌名}你单曲循环了没
2. 你也在玩{游戏}啊，现在打到哪了
3. 昨晚{球队}那场你看了吗，最后那一下我人都站起来了
4. 你也追{作品}！你站哪个角色

生硬：
- “我们都喜欢{歌手}，这说明我们很有缘分。” → 只陈述共同点，没给对方好接的问题
- “请问你最喜欢{歌手}的哪三首歌？为什么？” → 像问卷，一次问太多

## E 类：同处境

自然：
1. 你也在准备{考试}？现在每天几点收工
2. 看到你也在找实习，投简历投到怀疑人生了吗
3. 你也是刚到{城市级别的描述，如“新城市”}，最先摸清楚的是哪家店

生硬：
- “我们都在{学校}，真巧。” → 违反 H3，学校属于不提的敏感信息
- “备考压力很大吧，要注意身体。” → 像长辈问候，没有同龄人的语气

## B 类：同类型（先具象化）

自然：
1. 你也爱看悬疑片，最近有哪部让你猜错结局的
2. 看你也听独立音乐，有没有私藏的乐队推荐一个
3. 你也玩卡牌策略，现在主玩哪个

追问对上之后（升级为 A）：
- 我也超喜欢那部！你是第一遍就看出来了吗

追问对不上（互相推荐）：
- 这部我还没看过，记下了。换我推荐一部你可能会喜欢的：{作品}

生硬：
- “你喜欢悬疑片，我也喜欢悬疑片。” → 停在类型层，没有往具体走

## D 类：互补

自然（由新手一方的分身发问）：
1. 看你会弹吉他，我一直想学，新手最先卡在哪
2. 你是{游戏}老玩家吧，我刚入坑，有什么一定别做的事

生硬：
- “你可以教我吉他吗？” → 第一次聊就提请求，压力太大

## C 类：同活动（邀约阶段）

自然（聊到第 6 轮以后或接管前）：
1. 你也喜欢爬山，{山或路线}我一直想去，哪天天气好可以一起
2. 那部电影下周上映，到时候可以约一场
3. 听你这么说想去那家店了，下次可以一起去试试

生硬：
- 第一句就说“我们都喜欢爬山，周六一起去吧” → 还没聊熟就约，违反 S4
- “周六下午两点在山脚见” → 替真人定时间地点，违反 H6

## 没有共同点时（S7）

自然：
1. 看你很喜欢{对方热度最高的兴趣}，这个我完全没接触过，入坑的契机是什么
2. 你的{兴趣}看起来好有意思，新手从哪开始比较好

生硬：
- 硬凑一个不存在的共同点 → 违反 H1
